# TouchDock Mac 다운로드

TouchDock은 iPhone을 Mac의 트랙패드와 입력 장치로 사용하는 앱입니다. 이 저장소는 Mac 설치 파일을 배포하며 소스 코드는 포함하지 않습니다.

## 다운로드

[최신 버전 다운로드 페이지](https://github.com/rudadlswh/TouchDock-Downloads/releases/latest)

[TouchDock Mac 1.0 DMG 다운로드](https://github.com/rudadlswh/TouchDock-Downloads/releases/download/v1.0.0/TouchDock-Mac-1.0.dmg)

- macOS 14.0 이상
- Apple Silicon 및 Intel Mac 지원
- Developer ID 서명 및 Apple 공증을 확인한 앱 포함
- 함께 사용할 iPhone용 TouchDock 앱 필요

## 설치

1. Mac에서 DMG를 다운로드하고 엽니다.
2. `TouchDock Mac.app`을 `Applications`로 드래그합니다.
3. 응용 프로그램 폴더에서 TouchDock Mac을 실행합니다.
4. 앱 안내에 따라 시스템 설정의 손쉬운 사용 권한을 허용합니다.
5. Mac에 표시된 페어링 QR 코드를 iPhone용 TouchDock 앱으로 스캔합니다.
